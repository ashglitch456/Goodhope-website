## Sources (all found via web search this run, 2026-09-02)

1. **TIA Recommended Practice RP-01-01 "Tire Profiling" — three objectives of buffing (size to tread/mold width, shape to crown radius, prep surface for adhesion); buffing radius varies by tire brand, size, construction, and type; best practice is to profile three worn casings of the same brand/series/size to develop buff parameters** — Tire Industry Association, RP-01-01 (tireindustry.org/pub/?id=C62B5B48-1866-DAAC-99FB-F932FD7587CB), surfaced via web search (full document not directly fetchable — egress-blocked — but summarized content matches multiple corroborating search results).
2. **Rasp blade radius/contour selection varies by tire brand, size, and construction; cone, radius, cup, and contour blade shapes serve different casing geometries** — McGee Company, "Pincott Rasp Blades" (mcgeecompany.com/retreading-basics/pincott-rasp-blades/); Ascot Supply Corporation retreading buyer's guide (rubber-inc.com), both surfaced via web search.
3. **Rotary gouges remove large amounts of loose/damaged rubber; used at roughly a 90° angle during injury prep** — TECH Tire Repair Supplies product descriptions (products.techtirerepairs.com, gouges category), surfaced via web search.
4. **Carbide cutters remove damaged steel cable/wire in radial tires on a low-speed drill (~1,200 RPM max), minimizing injury size** — TECH Tire Repair Supplies (products.techtirerepairs.com, carbide cutters category), surfaced via web search.
5. **Standard radial truck tire repair sequence: rotary gouge/knife for bulk removal → coarse-grit rasp on low-speed buffer (5,000 RPM max) → medium-grit rasp to texturize** — TECH RM-8 Radial Truck Tire Repair Method manual (techtirerepairs.com/wp-content/uploads/2019/09/RM8_truck_tire_repair_singlepg9-19.pdf), surfaced via web search.
6. **Aluminum/white oxide stones are used on a high-speed grinder specifically to dress/cut exposed steel cord in steel-belted radials, distinct from general rubber-removal rasps** — summarized from web search of TECH Tire Repair Supplies product listings and general tire-repair trade sources.
